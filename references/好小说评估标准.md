# 好小说评估标准（AI 自查用）· 双轴抽样框 + 共性特征 + 量化路径

> **前提一：不存在单一的「公认前 100」。** 豆瓣、BBC、TIME、茅盾奖、网文榜口味互不重合，任何合并排名都是构造物。  
> **前提二（v1.2.1 修正）：单轴排名从根上就是错的。** 第一版按"奖项/评论家"计分，把《全职法师》《大王饶命》《夜的命名术》《龙族》这类**读者规模巨大**的作品全筛掉了——那不是它们不够好，是**尺子只量了一个方向**。  
> 所以本版改用**双轴**：文学性（L）× 传播力（R），四象限取样。榜单是手段，不是结论。

---

## 一、筛选依据：双轴 + 分层配额

### 1.1 双轴定义

| 轴       | 记号    | 量什么                   | 5 分             | 3 分        | 1 分    |
| ------- | ----- | --------------------- | --------------- | ---------- | ------ |
| **文学性** | **L** | 语言精度、结构复杂度、人物深度、主题余味  | 可反复重读、进文学史      | 类型内上乘、技法完整 | 通顺但无余味 |
| **传播力** | **R** | 读者规模、改编/跨媒介、类型开创、长销能力 | 现象级（千万级读者/全民改编） | 垂类头部       | 小圈层    |

### 1.2 四象限（★ 本版核心）

| 象限          | L / R | 典型               | 为什么必须在样本里                     |
| ----------- | ----- | ---------------- | ----------------------------- |
| **Q1 双高**   | 高 / 高 | 红楼梦、三体、哈利波特、诡秘之主 | 证明"好看"和"耐读"不矛盾                |
| **Q2 高L低R** | 高 / 低 | 边城、围城、雪国         | 提供语言与留白的上限                    |
| **Q3 低L高R** | 低 / 高 | 斗破苍穹、全职法师、大王饶命   | **网文为什么有人追的直接证据**——第一版正是缺了这一格 |
| **Q4 双低**   | 低 / 低 | —（不取样）           | 无学习价值                         |

> **硬规则**：Q1/Q2/Q3 **三格都必须有样本**；**Q3 不得少于 30 本**。缺了 Q3，标准就会把"爽"当成原罪，写出没人看的"correct 小说"。

### 1.3 来源（只作 R 轴的证据，不再一票定生死）

| 代号     | 来源                                     | 主要贡献               | 偏差      |
| ------ | -------------------------------------- | ------------------ | ------- |
| **S1** | 豆瓣读书 Top 250                           | 中文读者口碑             | 偏文艺     |
| **S2** | BBC Culture 100 Greatest Novels (2015) | 国际评论界共识            | 英语视角    |
| **S3** | TIME All-TIME 100 Novels               | 大众智识视角             | 截止 2005 |
| **S4** | 茅盾文学奖（1982–2023）                       | 中文长篇结构标杆           | 偏现实主义   |
| **S5** | 起点/番茄/七猫榜单、网文双年奖                       | **读者规模与追读**（R 轴主证） | 商业性强    |

| **S7** | **实体销量、改编票房/收视、翻译语种数**                 | **跨媒介传播力**（R 轴补充）  | 营销可造假   |

### 1.4 分层配额

| 层              | 配额     | 作用                     |
| -------------- | ------ | ---------------------- |
| A 中文文学经典       | **15** | L 轴上限标杆                |
| B 中文网络文学       | **48** | **主样本**：同题材、同连载条件、同读者群 |
| C 世界文学与类型      | **22** | 结构/视角/世界构建的可迁移技术       |
| D 中文类型·青春·实体畅销 | **15** | 跨媒介与女频/青春现象（龙族、三体、魔道等） |

### 1.5 去重与争议

- 同一作者**最多 3 部**（防止一个作者霸榜；已对乌贼/耳根/猫腻/土豆/辰东/西红柿/肘子/江南逐一核过）。
- 系列按首部计（《魔戒》不拆三部；《哈利波特》取首部）。
- 编号 `层-序号` 只是**抽样编号**，不是名次；层内按（L+R, 影响力）排。

## 三、共性特征：这 100 本共享什么

> 每条配**反例**——只写"要具体"没用，写出"什么算不具体"才能自查。

### 3.1 情节（Plot）

| #  | 共性       | 具体表现              | 反例             |
| -- | -------- | ----------------- | -------------- |
| P1 | 因果闭环     | 结果能追到前因；偶然只开局、不解局 | 正好路过、正好听见、正好捡到 |
| P2 | 目标—阻碍—代价 | 每章有**可判定成败**的当下目标 | 整章在"调查/思考/赶路"  |
| P3 | 信息差驱动    | 读者/角色/对手知道的不一样    | 所有人都知道，只是没人说   |
| P4 | 承诺兑现     | 开篇的期待在中段真的兑现      | 画大饼、中段换题       |
| P5 | 反转可回溯    | 反转前的细节都在          | 靠新角色/新设定空降     |

### 3.2 人物（Character）

| #  | 共性         | 具体表现                 | 反例           |
| -- | ---------- | -------------------- | ------------ |
| C1 | 欲望/需求/恐惧三角 | 表面要什么、深层缺什么、怕什么，互相拉扯 | 只有一个目标、没有代价  |
| C2 | 言行可辨       | 遮名能认出是谁在说话           | 所有人同一种书面语    |
| C3 | 弧线有位移      | 起点信念 ≠ 终点信念          | 经历一切后想法没变    |
| C4 | 配角有自己目标    | 配角会为自己的事**违背**主角     | 只负责递消息、送人头   |
| C5 | 压力下选择暴露性格  | 用"他选了什么"定义人          | 靠旁白"他是个善良的人" |

### 3.3 结构（Structure）

| #  | 共性      | 具体表现                           | 反例             |
| -- | ------- | ------------------------------ | -------------- |
| S1 | 节拍落点    | 关键节点落在 ~12-15%/25%/50%/75%/90% | 高潮 60% 用完，后段泄气 |
| S2 | 章末钩子    | 收在"多知道一点/多怕一点"                 | 章末总结句、抒情句      |
| S3 | 伏笔闭环    | 埋了必收；不收要正式弃用                   | 埋了三十章没人提       |
| S4 | 卷末收束    | 本卷主线闭合，只留一卷引子                  | 卷末还在开新坑        |
| S5 | 一场戏一个功能 | 每场只干一件事（推进/揭示/关系）              | 一场塞五个功能，全没做透   |

### 3.4 文笔（Prose）

| #  | 共性       | 具体表现            | 反例              |
| -- | -------- | --------------- | --------------- |
| W1 | 具体优先     | 名词、动词承担信息，形容词克制 | "美丽的、宏伟的、令人震撼的" |
| W2 | 白描       | 情绪落在手、眼、物件、空间   | "他心中涌起一股……"     |
| W3 | 比喻长在故事土壤 | 喻体来自本书世界        | 都市文硬塞深海、宇宙      |
| W4 | 视角一致     | 贴身写就只写他能感到的     | 突然全知："他不知道的是……" |
| W5 | 对话有潜台词   | 说的和想的不一样        | 人物把心里话完整说出来     |

### 3.5 节奏（Pacing）

| #  | 共性     | 具体表现          | 反例          |
| -- | ------ | ------------- | ----------- |
| R1 | 张弛交替   | 高强度后有缓冲，缓冲里埋雷 | 连续五章高潮，读者麻木 |
| R2 | 句长变化   | 紧张处短句，铺陈处长句   | 全篇同一句长      |
| R3 | 信息释放速率 | 每章新增设定有节制     | 一章塞十个新名词    |
| R4 | 场景切换干净 | 换场有锚点（温度/光/声） | 直接跳，读者不知在哪  |
| R5 | 段落短    | 对话段 1~3 句     | 大段不分行       |

### 3.6 传播层（Reach）★ 第一版缺的那一维

> 这一层解释的是"**为什么有人追**"，与文学性并列、不 subordinate。

| #  | 共性    | 具体表现                 | 反例             |
| -- | ----- | -------------------- | -------------- |
| T1 | 开篇即冲突 | 前 300 字出现危险/羞辱/损失/异常 | 先写三千字世界观       |
| T2 | 爽点密度  | 每 3~5 章一个小兑现         | 憋到 30 章才给第一次   |
| T3 | 信息门槛低 | 新名词 ≤3/章，且**当场能用**   | 名词解释大段插入       |
| T4 | 情绪价值  | 替读者出气/解压/补偿/燃        | 全程憋屈，无处释放      |
| T5 | 追读驱动  | 章末有"必须看下一章"的理由       | 章末把话说尽         |
| T6 | 主角可代入 | 能力/处境/道德坐标让人愿意代入     | 主角圣到不像人，或渣到不想跟 |

### 3.7 元特征（跨维度）

1. **具体性优先于概括性**——不写"他很痛苦"，写他做了什么。
2. **因果必然优先于巧合**——巧合可开局，不可解局。
3. **情感真实优先于情感强烈**——不煽情，读者自己会难受。
4. **留白优先于说尽**——把判断留给读者。
5. **可重读性**——第二遍还能读到新东西。

## 五、下一步方法：六步把 100 本变成可执行标准

### 第 1 步 · 抽样（1 天）


- 100 本 × 3 段（开篇前 3 章 / 中段随机 1 章 / 高潮前 1 章）= 300 样本
- **必须按象限分层**：Q3 样本不得少于 96 个（32 本 × 3 段），否则标准又会偏回文学性
- 产物：`样本清单.csv`（编号/作品/层/象限/段位/来源/版权状态）

### 第 2 步 · 合法取文（★ 版权红线）
- **公版**（鲁迅、老舍、塞万提斯、托尔斯泰等）：可取全文，只做内部统计
- **在版/网文**：**不全文入库**；只取授权样本或作者自购，入库只留**指标 + ≤3 句引用**
- 产物：`样本/<层>/<编号>.md`（仅授权/公版），其余只入指标表

### 第 3 步 · 机器初测（1 天）
```bash
python scripts/lint_prose.py <样本目录> --json 层.json
python scripts/analyze_arc.py <样本目录> --json 层-arc.json
python scripts/calibrate.py  <样本目录> --out 层-报警线.md
```
- **按象限分别校准**：Q1/Q2/Q3 各一套阈值——用 Q1 的标准要求 Q3，必然全灭

### 第 4 步 · 人工标注（3~5 天）
- 抽 30 个样本双人标注（M02/M03/M06/M07/M09~M12/M28~M33）
- **Cohen's κ ≥ 0.6** 才算可信；低于 0.6 说明口径不清，回改 §4.1
- 产物：`标注表.csv` + κ 报告

### 第 5 步 · 统计与筛选（1 天）
- 取 **P10/P50/P90**，不用均值
- **目标线 = P50 × 1.25**；**报警线 = P90 × 1.25**（越低越好用加性余量，见 `calibrate.py`）
- **区分度检验**：好样本 / AI 生成 / 明显差稿 三组，算 AUC；**AUC < 0.7 剔除**
- 产物：`指标-分位-AUC.csv`

### 第 6 步 · 落库（半天）
- 通过检验的指标写回 §4.1（替换"待校准"）
- 报警线写回 `anti-ai-rules.md`「两条线要分清」
- `calibrate.py` 加 `--baseline` 读基线 JSON；版本 +1

### 验收

| # | 验收项 | 通过标准 |
|---|---|---|
| 1 | 象限覆盖 | Q1/Q2/Q3 齐；**Q3 ≥30 本** |
| 2 | 标注可信 | κ ≥ 0.6 |
| 3 | 指标有区分度 | 保留指标 AUC ≥ 0.7 |
| 4 | 可复算 | 换一批样本重跑，结论方向不变 |
| 5 | 版权合规 | 在版作品无全文入库 |

## 六、已知局限

1. **L/R 分级是主观的**：本文档的 1~5 分由我给出，你可以直接改格子；改完只要配额仍成立，抽样框就有效。
2. **双轴不等于质量总分**：L 高 R 低（边城）与 L 低 R 高（斗破）都是好样本，**不要合成一个分数排名**。
3. **时代偏差**：19 世纪节奏不能要求日更网文；跨层只学方法，不搬指标。
4. **题材偏差**：悬疑的对话密度和言情不同；阈值必须分题材。
5. **幸存者偏差**：入榜都是"活下来的"，看不到同写法但失败的作品。
6. **可量化边界**：M18（比喻土壤）、M09（弧线）、M31/M32（追读/代入）只能人工判；**能量化的是下限，不是上限**。
7. **AI 检测 ≠ 好坏**：能区分"人/AI"不等于能区分"好/坏"，必须做第 5 步三组 AUC。
