# 三幕 · 十五节点节拍表（网文适配）

> 把一本书的总进度切成 **三幕 + 15 个必过节点**，用来回答一个具体的问题：**这一段该给读者什么**。
> 本技能自己的节拍工具，按中文长篇网文的节奏重排过（节点位置按**总章数百分比**算，不按页数）。
> 定位：可选节拍参考，**不替代、不动现有六步与门**。

## 一、为什么需要它

② 梗概的七要素 + 三幕节点（25·50·75）能锁住骨架，但颗粒度还停在「幕」。中段塌方、爽点憋太久、钩子断连这些病，都是**节点级**出的问题。这张表把三幕再切成 15 个可对照的节点，适合：

- 类型商业文（爽文 / 悬疑 / 爱情）确保「承诺的兑现」不落空；
- 自查中段是否塌方、钩子是否连得上；
- 与 `pipeline-stages.md` ②的三幕节点表互相对照（本表更细）。

---

## 二、三幕结构（与 ② 梗概三幕节点互证）

| 幕 | 占比 | 任务 |
|---|---|---|
| 第一幕（入局） | 0–25% | 建立主角日常 → 打破平衡把他推出去 → 落点不可逆 |
| 第二幕（对抗） | 25–75% | 兑现承诺 → 中点反转 → 压力收紧 → 跌到谷底 |
| 第三幕（清算） | 75–100% | 暗夜后重整 → 决战 → 收束 |

> 把 ② 梗概里的「打破平衡 ~12–15% / 中点 50% / 一无所有 ~75% / 高潮 ~90%」**对齐**到下面 15 个节点即可。

---

## 三、15 个节点

| # | 节点 | 落在哪 | 这一节点要发生 |
|---|---|---|---|
| 1 | 开场画面 | 第 1 章 | 用一个画面定调：主角的「之前」状态。读者立刻知道这是什么世界、什么情绪 |
| 2 | 主题抛话 | 前半段某章 | 借配角之口抛出「这本书在讲什么」的那句话。别让主角自己悟，留到结尾呼应 |
| 3 | 铺垫 | 0–10% | 主角的缺陷 / 匮乏交代清楚，读者同情他；埋下核心谜题的引子 |
| 4 | 打破平衡 | ~10–12% | 一件主角躲不开的事发生，旧生活结束。网文里通常就是那个「系统 / 血案 / 退婚」 |
| 5 | 内心拉扯 | 打破平衡后几章 | 主角「要不要接」的挣扎——给「恐惧」（驱动力三角）一个出口，别让他秒答应 |
| 6 | 入局 | ~25% | 主角**决定行动**，进入新世界 / 新规则，不可逆 |
| 7 | 副线登场 | 第二幕上半 | 感情线 / 搭档线 / 另一条「软」线启动，承载主题，也给读者喘口气 |
| 8 | 承诺兑现期 | 25–50% | **读者买这本书想看的东西**：爽点、脑洞、打脸、解密——高频兑现，别憋着 |
| 9 | 中点反转 | 50% | 伪胜利或伪惨败 + **反转**：目标升级、赌注变大，故事换挡 |
| 10 | 压力收紧 | 50–75% | 各方压力同时逼近，之前的小胜开始反噬，盟友动摇 |
| 11 | 一无所有 | ~75% | 主角失去最多（人 / 物 / 信念），全书最低点 |
| 12 | 灵魂暗夜 | 75% 后 | 短暂静止，主角直面自己在「铺垫」里埋下的那个缺陷 |
| 13 | 重整出手 | ~80% | 想通了，带着新认知重新上场——代价已付，方向已明 |
| 14 | 决战 | 90–100% | 与核心冲突正面清算，伏笔回收，新秩序建立 |
| 15 | 终场画面 | 末章 | 与开场画面**对位**：主角的「之后」状态，主题闭环 |

## 四、10 种故事原型（选题 / 梗概阶段对照）

| 原型 | 核心问题 | 典型落点 |
|---|---|---|
| 密室威胁 | 怎么消灭 / 逃出那个威胁 | 封闭空间 + 一个躲不掉的对手（实体或隐喻） |
| 上路寻获 | 去找 X，归来时人已不同 | 公路 / 任务线，伙伴一路集结 |
| 天降外挂 | 得到一个东西，代价是什么 | 外力带来的失控，越强越乱 |
| 祸从天降 | 坏事砸到普通人头上怎么办 | 被动卷入，被迫成长 |
| 成人礼 | 越过那道门槛意味着什么 | 时间节点（成年 / 毕业 / 至亲离世）驱动 |
| 冤家搭档 | 两个不对付的人怎么互相改变 | 双主角，关系的推进就是主线 |
| 真相追问 | 发生了什么、为什么发生 | 谜题驱动，信息分层释放 |
| 弱者逆袭 | 被看轻的人怎么翻盘 | 弱者视角，打脸是天然爽点 |
| 对抗庞然大物 | 一个人怎么撬动一套规则 | 系统性压迫 + 找缝隙破局 |
| 超凡者入世 | 有能力的人该怎么做人 | 能力带来的身份两难 |

> 选题 / 梗概阶段先用这张表定「这是什么类型的爽」，再回填 ② 梗概七要素；原型**决定第 8 节点该兑现什么**——弄错了原型，前面写再热闹读者也不买账。

---

## 五、与本技能的接线方式

- **② 梗概**：写完七要素后，用「三幕节点表 + 本表 15 节点」做一次节拍对齐，确认卷末落在哪个节点。
- **③ 目录 / ④ 章纲**：可把「悬念类型 / 伏笔操作」与节拍对齐（如打破平衡章标 `[爆]`、承诺兑现期连章标 `[爆]`、灵魂暗夜标 `[静]`），供 `analyze_arc.py --zhanggang` 读标记做「认知过山车」检测。
- **⑥ 复查**：用第 8 节点（承诺兑现期）反查——读者期待的高光，是不是真在该兑现的区间兑现了。

> 「兑得够不够爽」属于主观判断，得人工 / AI 裁决；`analyze_arc.py` 只负责客观的「连续高强度无缓冲」预警。
