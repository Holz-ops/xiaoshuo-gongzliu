# 平台规格与读者留存

以番茄小说为主，其他平台可参照。

## 硬规格

| 项 | 值 |
|---|---|
| 每章字数 | **2000~3000 字**（口径：去空白后的字符数，含标点，标题行不计） |
| 章末 | 必须留钩子 |
| 章节切分 | 按故事节拍切，不按排版切 |
| 更新 | 稳定日更优先于单章爆发 |

## 九项核心数据（诊断时向用户索取）

1. 点击率
2. 阅读人数
3. 加书架数 / 书架比
4. 追更人数 / 追更比
5. 催更数
6. 章节读完率
7. 万字读完率
8. 流量来源分布
9. 收益

诊断逻辑：

- **点击率低** → 封面/标题/简介问题，不是正文问题
- **读完率低（章节）** → 开局没钩子、节奏拖
- **万字读完率低** → 主线不清晰、目标不明（读者不知道在追什么）
- **书架比低** → 前 10 章吸引力不足
- **追更比低** → 钩子弱、更新不稳

## 前 10 章检查清单（最重要的一张表）

读者在前几章决定去留。以下五项**必须让读者看见**，明示或暗示都行，但不能没有：

| # | 检查项 | 落地做法 |
|---|---|---|
| 1 | **主角目标明示** | 第 1 章就给出可量化的长期目标（如「攒够十二万 → 买船票 → 开自己的店」），并在卷末呼应 |
| 2 | **主线可见** | 把主线的第一件事与主角目标绑定（如「这台机修好之前，你哪也别想去」）。埋得太深等于没埋 |
| 3 | **世界观成段交代** | 借新人视角在进城/入学/入职路上成段带出一次（150 字内），不做说明文 |
| 4 | **时间推进感** | 场景转换处加时间锚（「这是他来的第 X 天」「第二周」）。成本极低，效果立竿见影 |
| 5 | **空降元素先预告** | 「预告—引爆」两段式：先埋传闻级暗示（墙上的失踪启事、一句闲聊），再到原位置引爆 |

**外部读者的真实反馈（原话）**：
> 「看了前几章，主角的宏大目标也没有」「要主线没主线，要时间线没时间线，直接把那几个东西突然间就丢进来了，也没有设置悬念」「你明示也好，暗示也好，至少要让读者知道」

## 爽点与节奏排布

- **两章一次小爽点**（技术碾压、识破、占上风）
- **五章一次硬爽点**（打脸、逆转、关键突破）
- 悬疑推进章不能连着超过 3 章，中间要插一次释放

## 常见结构失衡

| 症状 | 修法 |
|---|---|
| 支线过多（五条线同时铺） | 明确主次，把可合并的支线并入主线势力 |
| 配角功能化（只负责递消息） | 给至少一个配角一条自己的线与一次抉择 |
| 主角太稳、没有怕 | 危险场景先给一笔「想跑」的内心，再行动 |
| 卷末收不住 | 用一纸调令/一道命令/一次袭击把所有人推到同一个方向 |
