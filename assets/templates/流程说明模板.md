# 流程说明（这本书怎么跑）

> 本目录只放**说明书与流程图**。流程本体（skill `xiaoshuo-gongzliu`）在书目录**外面**，不复制进来——否则书里那份迟早会变成旧版。
> 一本书 = 一条流水线（单书隔离）：不与其他书共用设定、章纲、进度卡、问题本。

## 二、文章怎么走（核心）

一章的旅程：

```
① 写出来     → 006 文章\扩展文章\          （按章纲扩写）
② AI 排查    → 006 文章\ai复查文章\        （查出的问题进 009 其他\问题本\ai查出的\）
③ 人工排查   → 006 文章\人工复查文章\      （人提的意见进 009 其他\问题本\人查出的\）
④ 定稿       → 007 最终文章\               （通过，交付用）
```

**每一轮排查，意见和改完的文章都有各自的位置**——哪个环节有问题，就在那一轮里找。

**文章在哪一格＝走到哪一步**（判断进度就看这个）：

| 状态 | 在哪一格 |
|---|---|
| 刚扩写完，还没查 | `006 文章\扩展文章\` |
| AI 查完/改完，**等人确定** | `006 文章\ai复查文章\` |
| 人确定/改完，通过 | `006 文章\人工复查文章\` |
| **真正定稿** | `007 最终文章\` |

> **铁律：没过人的那一关，绝不放「最终文章」。**
>
> **当前**：（把这一行改成实际状态——例：`007 最终文章` = 第 X~Y 章；`006 文章\ai复查文章` = 正在等人的那几章）

**每一步搬走之前，旧版自动存进 `009 其他\版本\`——所以任何时候都能翻出任一版来对比，数据不会流失。**

## 三、六个步骤与门（主干）

```
续写入口：素材体检 + 定基准 ┐
                            ├→ ① 报告 → ② 梗概 → ③ 目录 → ④ 章纲 → ⑤ 正文
新书入口：头脑风暴 ─────────┘                              （章纲总结）  │
                                                                        ↓ 自动衔接（不停顿、不等确认）
                        ⑥ 复查：AI 自查 → AI 据报告改稿
                                        ↓
                        同时输出「修改报告 + 改后文章」→ ★ 门（等人工确认）
                                        ↓
                        交付与交接（前置：⑥ 的门已确认）
```

**①②③④ 各一道人工确认门 + ⑥ 出口一道门**：展示完整产出 + 自检打勾 + 三选一（**通过 / 修改 / 重来**）。没确认，不进下一步。
**⑤ 生成正文不设门**：写完不停顿、自动衔接进 ⑥，由 AI 连做「分析 → 出报告 → 据报告改稿」，改完后才把「修改报告 + 改后文章」一起交给人确认——人只做裁判，不做搬运。

- **回卷**：下一卷回到 ③ 目录接着排，不必重做 ①②
- 进度记在 `008 进度\进度卡.md`

## 四、三层分工（问题在哪层，就回哪层找）

| 层 | 管什么 | 产物放哪 |
|---|---|---|
| 第一层 文章层 | 故事 / 人物 / 节奏 / 文风——**写出来** | `006 文章\扩展文章\` |
| 第二层 AI 检查层 | 字数 / 一致性 / 穿帮 / markdown——**查对不对** | `009 其他\问题本\ai查出的\` + `006 文章\ai复查文章\` |
| 第三层 人的层 | 节奏 / 爽感 / 人物讨不讨喜——**查好不好** | `009 其他\问题本\人查出的\` + `006 文章\人工复查文章\` |

## 五、章纲两条（务必分清）

| 条 | 在哪 | 状态 | 怎么用 |
|---|---|---|---|
| **先行章纲** | `004 目录\` | **已冻结，不许改** | 只当对比基准 |
| **总结章纲** | `005 章纲\` | 可更新 | **后续一律以它为准** |

## 六、三条不能破的规矩

1. **原稿只读**：`009 其他\版本\_原稿\` 永不动
2. **改前先快照**：动正文前，先把要改的复制进 `009 其他\版本\快照\<日期>-<批次>前\`
3. **每批必出成品包**：改完就把 `009 其他\批次成品\` 里那一包补好，否则等于没交付
